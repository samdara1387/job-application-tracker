# job-application-tracker
A Python application for recording, searching, and updating job applications with JSON storage.


## Features

- Add applications with a company name, job title, status, and timestamp.
- View saved applications.
- Search by company name.
- Update application statuses: Applied, Interview, Offer, or Rejected.
- Save and load records using a JSON file.
- Validate required company names, job titles, and status choices.

## Requirements

- Python 3
- No additional packages required.

## How to Run

1. Download this repository using **Code → Download ZIP**.
2. Extract the ZIP file.
3. Open a terminal in the extracted folder.
4. Run:

```bash
python "Job tracker.py"
```

5. Follow the numbered menu.

## Data Storage

The program creates `applications.json` in the folder where you run it. Run it from the same folder each time to access your saved records.

Personal application records are not included in this repository.

## About This Project

I built this project to practise Python loops, conditions, lists, dictionaries, input validation, exception handling, and JSON file storage.

This is an initial learning version with room for future improvements.
